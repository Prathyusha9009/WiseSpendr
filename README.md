### 📖 Overview

WiseSpendr is a modern expense management platform that helps users track spending, manage budgets, analyze financial habits, and make smarter financial decisions through visual analytics and AI-powered insights.
The platform provides a clean and intuitive interface for monitoring personal finances while offering meaningful insights into spending behavior.

### ✨ Features

 ### 💳 Expense Tracking
- Add and manage expenses easily
- Categorize transactions
- Real-time expense monitoring
- Track spending history

### 📊 Financial Analytics
- Spending trend visualization
- Category-wise expense analysis
- Interactive charts and reports
- Monthly financial summaries

### 🎯 Budget Management
- Set monthly budgets
- Monitor budget utilization
- Track spending against limits
- Budget progress indicators

### 🤖 AI Insights
- Smart spending analysis
- Personalized financial recommendations
- Savings suggestions
- Spending pattern detection

### 🔐 Secure Authentication
- User registration and login
- Email verification
- Secure cloud-based data storage
- Individual user expense management
